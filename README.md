# Delhi Metro Data Analysis
A comprehensive data analysis project using Python to evaluate, visualize, and extract insights from Delhi Metro transit data. The project investigates passenger patterns, route efficiency, ticket preferences, and financial performance.

# Features & Objectives
Based on the project structure, the analysis covers six major key performance indicators (KPIs):

Most Crowded Route Analysis: Identifying high-traffic paths to optimize train schedules.

Most Crowded Station Analysis: Pinpointing footfall bottlenecks across different stations.

Year-wise Passenger Analysis: Tracking growth trends in ridership over multiple years.

Ticket Type Usage Analysis: Evaluating consumer preferences (e.g., Smart Cards vs. Tokens/QR codes).

Distance vs. Fare Relationship: Analyzing the pricing structure and fare linearity against distance traveled.

Most Profitable Route: Assessing revenue generation to highlight the most lucrative metro lines.

# Tech Stack
Language: Python
